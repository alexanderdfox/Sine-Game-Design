Sine Game Design Hub

Unified vector · sine · audio pipeline. Create geometry, sequence sound, play assets, and ship pure-sine games that all speak the same ZIP + XML language.

How the pieces work together
Studio → exports frame / combinatorial .zip (manifest XML + .ogg)
Vector → loads those ZIPs, scrubs frames, visualizes waveform
Matrix → drops the same ZIPs onto puzzle tiles for sequenced playback
Game Studio → 3D pure-sine XML engine (dual players, custom controls), exports packages
Shared format keeps everything interoperable end-to-end.
